# Макет и PDF

## Как это устроено

- Документ собирается компонентами `@react-pdf/renderer` в `src/pdf`. Это не HTML: CSS сайта здесь не действует.
- Код генерации и просмотра загружается отдельно (`loadScriptPdf`, `lazy` в `LayoutScreen`). Основной файл сборки им не нагружается: зрителю ссылки PDF не нужен.
- PDF создаётся при открытии Макета, при правках на этом экране и при скачивании. Просто при открытии сайта он не создаётся.
- `useScriptPdf` живёт в `App`, а не в экране: при возврате в Макет сразу виден прошлый результат.
- Пауза 200 мс объединяет быстрые переключения. Новый запуск отменяет предыдущий.

## Превью

- Страницы рисуются на холстах через `pdfjs-dist`. Встроенный просмотр не подходит: мобильный Chrome показывал вместо него кнопку «Открыть».
- Новые холсты рисуются вне экрана и заменяют старые разом. Так превью не моргает и прокрутка не сбивается.
- Размер холста считается от ширины контейнера. Масштаб от `devicePixelRatio` на iPhone давал 18 Мп при лимите iOS 16,7 Мп.
- Превью прокручивается вместе со страницей, поэтому скрытие кнопок при прокрутке работает и здесь.

## Настройки

- Хранятся в localStorage отдельно от сценария, общие для всех сценариев. В ссылку и JSON не входят.
- Настройки листа видны, только пока лист включён.
- На ПК это столбец слева. На телефоне каждая настройка отдельная капсула в строке над кнопками: строка идёт от края до края и листается, группы разделены линиями. «Скачать PDF» на телефоне стоит между меню и «Поделиться».
- Если все листы выключены, вместо превью показывается сообщение, а скачивание неактивно: документ без страниц создать нельзя.

## Листы (A4)

1. Лист игрока: название, автор, четыре основные команды, логотип. Настройки: `playerSheet`, `columns`, `stretch`.
2. Лист рассказчика: по бокам порядок ночи, в центре Летописцы, Джинн с джинксами, Сказочники, Странники, таблица игроков. Настройки: `storytellerSheet`, `travellers`, `playersTable`, `nightOrderColumns`.
3. Подробный порядок ночи: две колонки с подсказками. Настройка: `nightOrder`.

## Правила вёрстки

- Размеры задавай через `mm()`, шрифты через `useFontSize()`: он учитывает настройку масштаба.
- Настройки компоненты читают из `PdfSettingsContext`.
- Секции и правила Джинна берутся из `getScriptSections`, общей с сайтом. Не пиши их второй раз.
- Цвета лежат в `pdfColors.ts`: CSS-переменные в PDF недоступны. Значения совпадают с `styles/colors.css`.
- Карточкам ставь `wrap={false}`, чтобы они не разрывались между страницами.
- У шрифта Petersburg нет жирного начертания, его имитирует `Bold`: копия текста со сдвигом.

## Порядок ночи

В него входят роли сценария и служебные записи без команды: `dusk`, `dawn`, `demoninfo`, `minioninfo`. При настройке «5-6 игроков» `demoninfo` и `minioninfo` скрыты.

## Проверка

Вёрстку PDF в jsdom не проверить: Node-сборка `@react-pdf` отличается от той, что работает у пользователя. Проверяй настоящий файл из браузера, переводя страницы в изображения.
