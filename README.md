# Редактор сценариев

Веб-приложение для создания, публикации и печати сценариев настольной игры Кровь на Часовой Башне. Работает в браузере, бэкенда нет. Есть поддержка мобильной версии.

[Открыть приложение](https://botc-ru.github.io/script/)

## Возможности

- Собрать сценарий из ролей
- Поделиться им ссылкой или JSON
- Распечатать PDF с листами для игроков и рассказчика

## Стек

- Vite, React, TypeScript. 
- PDF: `@react-pdf/renderer`
- Превью: `pdfjs-dist`.

## Ссылка на сценарий

Сценарий открывается по адресу с параметрами:

| Параметр | Значение |
|---|---|
| `title` | Название |
| `author` | Автор |
| `color` | Цвет заголовка |
| `roles` | Роли через запятую |
| `customOrder` | Показывать роли в порядке из `roles`. Без него роли сортируются автоматически |

Ссылкой считается адрес с `title` или `roles`. Без неё открывается последний сценарий, он хранится в браузере.

## Данные

Роли загружаются при запуске из репозитория [botc-ru/data](https://github.com/botc-ru/data), поэтому для работы приложения нужен интернет.

## Деплой

Пуш в `main` автоматически публикует приложение на GitHub Pages.
